AHORRO GRUPAL — ICONO DEL CERDITO MORADO

Esta actualización reutiliza el PNG morado que ya habías aprobado.
No se cambian el diseño morado, los datos, los pagos, Firebase, los fondos de $10 + $10 ni los Cron Jobs.

INSTALACIÓN
1. Haz copia de seguridad de tu carpeta del proyecto.
2. Abre tu carpeta AppAhorro (donde está package.json).
3. Extrae el ZIP aquí y ACEPTA reemplazar los archivos.
   Importante: NO se crea una carpeta adicional y NO se incluye .git ni node_modules.
4. Abre una terminal de VS Code en esa carpeta y ejecuta:

   npm install
   npm test
   npm run build
   git add .
   git commit -m "Actualizar icono morado Ahorro Grupal"
   git push origin main

5. Comprueba el icono en la página y en Vercel.
6. Si la aplicación instalada todavía muestra el icono anterior, desinstala
   SOLO el acceso directo o la app PWA del dispositivo y vuelve a instalarla
   desde la página. No borres datos de Firebase. Los sistemas operativos
   pueden conservar el icono anterior incluso después de actualizar la web.
