src/App.jsx — const semanaActual=semanaPeriodo(periodo?.meta,fecha);

INSTALACIÓN:
1. Cierra únicamente Vite con Ctrl+C en su ventana (puedes dejar abiertos los emuladores).
2. Extrae el ZIP directamente en C:\Proyectos\AppAhorro y permite reemplazar src/App.jsx.
3. En esa carpeta ejecuta los siguientes comandos por separado:
   npm run lint
   npm test
   npm run build
4. Si pasan, inicia npm run dev y recarga http://localhost:5173.
5. Asegúrate de seleccionar el ciclo 2026-2027-A. La demostración usa lunesBase=2026-10-19 y semanaBase=4. El 31/10/2026 corresponde a la semana 5 y el 02/11/2026 corresponderá a la semana 6.
