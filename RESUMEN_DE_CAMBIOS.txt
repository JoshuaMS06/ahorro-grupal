INSTALAR EN TU PROYECTO YA PUBLICADO
1. Extrae el ZIP.
2. Copia el contenido de la carpeta AhorroGrupal_Actualizado en tu proyecto
   actual de Visual Studio Code, sustituyendo archivos coincidentes.
3. NO borres la carpeta oculta .git de tu proyecto actual.
4. En la terminal de tu proyecto:
       npm install
       npm run dev
5. Comprueba que el diseño y los pagos cargan correctamente. Luego:
       npm run build
       git add .
       git commit -m "Ajustes visuales morados Ahorro Grupal"
       git push origin main
6. Vercel actualizará la web si está enlazado a tu rama main.
7. Cierra y reabre la PWA instalada. En la web usa Ctrl+F5 si ves
   el tema anterior. Si aún aparece por caché, reinicia la app o
   reinstálala desde el navegador.

NOTA: Este ZIP es el código fuente completo, no incluye node_modules
ni la carpeta .git. Conserva tu repositorio y configuraciones locales.
