CÓMO ACTUALIZAR:
1. Haz copia de tu carpeta de proyecto.
2. Extrae este ZIP DIRECTAMENTE dentro de esa carpeta. Conserva .git, no borres tu base de datos.
3. npm install
4. npm run build
5. git add .
6. git commit -m "Revisar permisos Firebase en tiempo real"
7. git push origin main

QUÉ COMPROBAR:
1. Abre la web desplegada en ventana de incógnito.
2. Inicia sesión como administrador.
3. Si no accede, revisa el texto bajo UID, que ahora indica si se leyó null, un texto o hubo un error.
4. Usa "Volver a comprobar el permiso". Si persiste, conserva el mensaje exacto para diagnosticarlo.

IMPORTANTE: los datos en /ahorro permanecen intactos. No se cambian las reglas de Firebase.
